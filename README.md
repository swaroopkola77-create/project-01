# Swaroop Kola — Portfolio

Personal portfolio website built with React and Vite.

## Purpose

A responsive single-page portfolio for showcasing projects, technical interests, learning progress, and contact information.

## Tech stack

- React
- Vite
- CSS
- Google Fonts
- Vanilla browser APIs for interactions

## Features

- Responsive portfolio layout
- Pointer-responsive hero typography
- Expandable project details
- Desktop project preview interaction
- Active section navigation
- Clipboard email action
- Accessible keyboard focus states
- Reduced-motion support
- Light and dark color themes

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Deployment

The project is configured as a standard Vite application and can be deployed directly to Vercel.

### Vercel settings

- Framework preset: Vite
- Build command: `npm run build`
- Output directory: `dist`
- Install command: `npm install`
