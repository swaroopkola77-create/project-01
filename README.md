# Swaroop Kola — Portfolio

A polished React + Vite portfolio adapted from the supplied Cloud-generated HTML/CSS/JavaScript concept.

## Stack
- React
- Vite
- CSS
- Responsive design
- Accessible accordion interactions
- Pointer-responsive hero typography
- Project preview interaction
- Clipboard email copy

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
npm run preview
```

## Project structure
- `src/App.jsx` — React components, portfolio data and interactions
- `src/App.css` — responsive visual system and animations
- `src/main.jsx` — React entry point
- `src/index.css` — global reset/root sizing
